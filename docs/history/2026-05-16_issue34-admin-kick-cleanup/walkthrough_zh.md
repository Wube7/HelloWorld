# 實行紀錄：管理員強制登出與離線匿名帳號自動清理

本份文件紀錄了為強化使用者清單管理權限，所進行的管理員強制踢人按鈕 (`🚷`) 廣播機制與離線匿名帳號全自動資料庫清理功能的具體實踐成果。

## 執行變更

### 即時名單管理 (`script.js`, `admin.js`)
1. **管理員強制登出 (踢人機制)**：
   - 在連線登入後建立對 `admin/kicklist/${user.uid}` 的即時監聽。
   - 當偵測到被踢廣播時，客戶端瞬間彈出警告通知，自動刪除線上狀態並秒速登出。
   - 在使用者清單中，管理員能於所有在線帳號旁看到 `🚷` 按鈕，點選即可精準傳送踢出廣播。
2. **離線匿名帳號清道夫**：
   - 於名單繪製流程中，自動過濾並隱藏所有未具備 WebSocket 線上狀態的匿名帳號。
   - 若當前操作者為管理員，系統會在背景自動發送刪除請求，將這些因為網頁直接關閉而殘留的資料庫幽靈節點全數清除乾淨。

## 驗證結果
- 經由 GitHub Actions 順利完成雲端建置並自動推送至測試站台。
- 點選 `🚷` 按鈕，目標視窗瞬間接收通知並強制登出。
- 離線匿名帳號在重整或斷線後，完美自名單與資料庫中自動蒸發。
