# 實行紀錄：實作即時創意徵集模式與加權佈告欄

本份文件紀錄了為全站引入第四大核心互動模式：**創意徵集模式 (Survey - Ideas)**，所完成的題庫管理、加權投票與即時卡片瀑布流展示成果。

## 執行變更

### 全端創意徵集與投票系統 (`database.rules.json`, `styles.css`, `admin.js`, `script.js`, `presenter.js`)
1. **題庫與場控管理 (`admin.html`, `admin.js`)**：
   - 建立動態題庫系統 (`/admin/ideaSurveys`) 支援新增、編輯與刪除。
   - 提供啟動徵集、追蹤即時總貼文數以及一鍵鎖定 (`🔒 Lock Session`) 按鈕，即時廣播凍結全場輸入與投票。
2. **加權投票與防弊機制 (`index.html`, `script.js`)**：
   - 參與者畫面呈現即時佈告欄與底部輸入列。每張卡片底部配備 `👍 +1` 與 `🔥 +2` 按鈕。
   - 資料庫嚴格追蹤單一使用者的投票紀錄 (`voters/$uid = val`)，參與者可自由對全場卡片給予加權評分，亦可隨時更改或點擊取消，但絕無法透過連點無上限洗分。
3. **大螢幕即時動態排序 (`presenter.html`, `presenter.js`)**：
   - 大螢幕與玩家端完美同步，即時執行加權排序演算法：得票點數最高者自動向上置頂，同分者由最新貼文優先排在上方。

## 驗證結果
- 經由 GitHub Actions 順利完成雲端建置並自動發布至測試站台。
- 玩家秒速送出點子與附議，大螢幕流暢動態重新排序，鎖定功能精準發揮場控效力。
