# 實行紀錄：遊戲模式常駐頁首與大廳切換按鈕

本份文件紀錄了為解決進入遊戲階段 (Quiz 作答或 KBC 競賽) 時，頁首導覽列被強制隱藏所產生的操作中斷問題，所進行的頁首常駐與即時視角切換按鈕實作成果。

## 執行變更

### 導覽與視角管理 (`index.html` & `script.js`)
1. **常駐導覽列**：
   - 移除了畫面模式切換時強制隱藏頁首 (`headerEl`) 的設定。現在無論在任何活動階段，輕盈緊湊的頁首導覽列皆穩定常駐於畫面頂端。
   - 作答者隨時可點選 `🚪 Log Out` 登出或展開線上名單，管理員亦能流暢地透過右上角的 `👑 Admin` 與 `📺 Presenter` 隨時開啟後台與投影頁面。
2. **自由切換大廳與遊戲**：
   - 在頁首新增了雙向視圖切換按鈕 (`💬 Chat` 與 `🎮 Game`)。
   - 當 Firebase 廣播正處於活躍的遊戲作答狀態時，作答者只要點擊 `💬 Chat`，即可秒速收合作答卡片並開啟全球聊天室參與對話；想回歸作答時再點擊 `🎮 Game`，即可瞬間彈回題目視窗，過程完全不中斷連線或答題進度！

## 驗證結果
- 經由 GitHub Actions 順利完成雲端建置並推送至測試站台。
- 遊戲啟動時，頁首導覽列成功常駐顯示。
- 點選大廳與遊戲按鈕切換順暢，視覺體驗與便利性均大幅提升。
