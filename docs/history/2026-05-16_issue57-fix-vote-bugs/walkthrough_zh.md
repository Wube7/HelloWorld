# 實行紀錄：實作原子投票事務與禁止作者自推

本份文件紀錄了為排查連點洗分與發送者替自己點子按讚，所完成的原子事務 (`runTransaction`) 與卡片作者校驗屏障成果。

## 執行變更

### 雲端原子事務與發文者防線 (`script.js`)
1. **原子投票結算 (`runTransaction`)**：
   - 廢除依賴過時本機端快取做差額運算的做法，全面升級為 Firebase 伺服器端原子事務 `runTransaction`。
   - 不論使用者點擊速度多快、網路延遲多長，所有加權運算與個人額度都會在雲端強制單線程原子化執行，徹底消除洗分漏洞。
2. **禁止發文者按讚**：
   - 於生成卡片時嚴格校驗 `item.uid === auth.currentUser.uid`。
   - 若為自身貼文，按鈕即時停用並附帶提示文字，確保評分附議客觀真實。

## 驗證結果
- 經由 GitHub Actions 順利完成雲端建置並自動發布至測試站台。
- 玩家發表點子後，自身卡片附議鍵精確呈灰階停用。
- 針對他人點子瘋狂連擊，總票數絲毫無算術疊加錯誤，防護完美無缺。
