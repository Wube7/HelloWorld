# 解耦問卷結束與重設及歸檔歷史快照大廳防護計畫

針對問卷評分與創意徵集兩大模式進行深度的商業邏輯與生命週期重構。將結束調查 (`End`) 與資料重設 (`Reset`) 徹底解耦，並在每次揭曉或結束時自動將作答結果快照 (`lastSession`) 封裝歸檔至題庫。題庫清單擴充為 `Start`, `Edit`, `Delete`, `Result` 四大操作，支援一鍵重現歷史分布圖。同時導入大廳互斥鎖 (`Mutex Locking`)，防止與其他進行中遊戲發生碰撞干擾。

## 使用者審查事項
請確認快照歸檔 (`lastSession`) 架構與大廳互斥鎖保護邏輯。

## 建議系統架構

### 1. 解耦與快照歸檔 (`admin.js`)
- 當按下 `End Survey` 或 `End Ideation` 時，僅將 `active` 切換為 `false`，讓全場平順退回大廳，不再粗暴刪除整個資料庫節點。
- 當管理員按下揭曉或結束徵集時，系統將該次作答結果 (`submissions`, `results`, `ideas`) 自動寫入該題庫節點的子目錄 `/admin/surveys/$sid/lastSession` 永久保存。
- 唯有重新按下 `Start` 或 `Edit` 時，才會精準重設清除舊有緩存。

### 2. 擴展題庫按鈕 (`admin.html`, `admin.js`)
- 題庫清單現在提供 `Start`, `Edit`, `Delete`, `Result` 四個按鈕。
- 當偵測到該題庫擁有 `lastSession` 時，`Result` 按鈕即時亮起。點擊後秒速將快照寫回啟動節點並設定 `phase: 'result'` (或 `locked: true`)，大螢幕瞬間重現歷史直方圖或卡片榜單。

### 3. 大廳狀態互斥保護
- 所有的題庫按鈕在點擊時皆受 `currentQuizPhase === 'idle'` 屏障保護。
- 若房間內正處於 Quiz、KBC 或其他問卷進行中，系統精準彈出提示要求先結束當前活動返回大廳，完美防止異步操作互相干擾。

## 驗證計畫

### 手動驗證
- 於後台開啟問卷，送出評分並點選揭曉。
- 按下 `End Survey` 返回大廳，確認資料庫節點未被抹除。
- 在題庫清單中觀察該題目的 `Result` 按鈕已啟用。點選 `Result`，大螢幕瞬間切換重現該次投票直方圖。
- 於作答進行中嘗試點選另一題目的 `Start`，確認被防護鎖擋下並彈出指引提示。
