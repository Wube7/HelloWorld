# 實行紀錄：同步登入時序修復提早跳轉與管理台卡死

本份文件紀錄了為排查 OAuth 選擇帳號時過早進大廳以及管理台驗證 pending，所完成的時序同步屏障與保底超時機制。

## 執行變更

### 非同步身分驗證同步機制 (`script.js`, `admin.js`)
1. **OAuth 執行屏障 (`script.js`)**：
   - 建立 `isGoogleAuthResolving` 鎖定變數。
   - 完美阻攔在彈出視窗尚未 resolving 完結前，底層快取異動引發的早期過渡快照觸發大廳解鎖。
2. **5 秒保底防卡死 (`admin.js`)**：
   - 建立 `authResolved` 追蹤器與 5 秒計時器。
   - 若遇多個分頁對 IndexedDB 產生事務競爭鎖定，5 秒後精準顯示指引文字，徹底消除死鎖卡死現象。

## 驗證結果
- 經由 GitHub Actions 順利完成雲端建置並自動推送至測試站台。
- 首頁點選 Google 登入，在彈出視窗挑選過程中，首頁歡迎卡片安靜穩定，不再閃現 Loading 大廳。
- 管理台開啟流暢順暢，防呆保險機制完備。
