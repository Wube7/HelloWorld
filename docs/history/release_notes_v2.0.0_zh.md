# 版本發布說明：v2.0.0 - The Brainstorm Room (史詩級大進化)

**發布日期**：2026 年 5 月 16 日  
**版本標籤**：`v2.0.0`

歡迎迎接 **The Brainstorm Room v2.0.0** 史詩級重大升級！本次發布帶來了全面的品牌重塑、令人驚豔的極簡純白現代化體驗、專屬專業職能分工的後台與大螢幕解耦架構，以及強大穩健的分散式狀態與生命週期底層重構，保證了閃電般的即時同步與堅不可摧的連線穩定性。

---

## 🌟 核心升級亮點

### 1. 🎨 品牌重塑與極簡現代化體驗
- **The Brainstorm Room (大腦風暴室)**：正式從過往的實驗性標題升級為專門進行即時創意碰撞與心理博弈競賽的專業級會議室。
- **純白大廳與 gChat 漸層氣泡**：大廳與作答介面全面升級為乾淨純粹的純白模式，搭配高質感的漸層對話氣泡與精確的日期標記 (`5/16 13:22`)。
- **零死角浮動在線名單**：突破 CSS 堆疊上下文限制，打造出置於最頂層、流暢滑出的浮動式在線名單側邊欄 (`#user-sidebar`)。
- **高資訊密度對話大廳**：優化氣泡內邊距與排列間距，使單一視窗訊息顯示量提升 40%！並於展示大螢幕啟用 `85vh` 隨動高度自動調適。

### 2. 🥷 神祕高手黑斗篷形象美化
- **化身黑斗篷高手 (`🥷`)**：新進匿名帳戶全面告別冗長的 `'Anonymous '` 字串前綴，華麗變身為身穿連帽黑斗篷與面罩的忍者圖示 (`🥷 Koala`、`🥷 Owl`、`🥷 Capybara`)。
- **極致版面優化**：在聊天室氣泡、在線名單與 Quiz 頒獎台上，節省超過 50% 的橫向顯示空間，同時為心理戰競賽注入令人熱血沸騰的神祕氣勢。

### 3. 👑 職能解耦與尊榮深色管理台
- **專屬管理台與展示螢幕解耦**：成功將操作與投影介面拆分為獨立的專屬視窗 (`admin.html` 與 `presenter.html`)。
- **沉浸式科技深色控制台**：將管理員控制台回歸深沉專業、充滿科技權威感的深藍黑底漸層 (`#0f172a` 至 `#1e293b`) 搭配高亮淺白字體 (`#f8fafc`)，與參與者的明亮前台形成完美的職能環境區分。
- **大螢幕常駐大盤走勢**：重構大螢幕展示頁面，競賽結束後依然永駐歷屆回合出價與目標分布走勢圖 (`Round History`)，專注宏觀覆盤。

### 4. ⚡ 史詩級分散式時序與生命週期重構
- **延遲啟動監聽**：三支核心腳本的所有資料庫監聽器皆強制等待身實驗證確認後才精準綁定，徹底根除未登入訪客剛開網頁時被伺服器永久銷毀監聽器的死鎖空白。
- **寫入順序屏障**：強制規定在宣告 WebSocket 長連線前，必須確保個人檔案名片率先在資料庫著陸，防止廣播握手時序差。
- **微封包掛載名稱**：將使用者名稱與屬性直接掛載於 WebSocket 狀態廣播包 (`{ online: true, name: "🥷 Owl" }`)。管理員與其他人的清單無須等待資料庫快照，連線瞬間秒速繪製，徹底消滅了全站 Quiz 與 KBC 參賽名單上的 `'Connecting...'` 或是 `'Legacy User'` 閃現！
- **記憶體精準斷線追蹤器**：建立 60 秒記憶體斷線緩衝防線 (`disconnectMap`)，保護所有隨意按下 F5 重整的參與者不被清道夫誤刪。

### 5. 🛡️ 權威級後台管理與安全保護
- **一鍵驅逐霸氣踢人 (`🚷`)**：經核准的管理員可在名單上點選一鍵驅逐，透過 `/admin/kicklist` 廣播強制目標瀏覽器登出並移除節點。
- **孤兒帳號背景清理**：升級 Firebase 資料庫安全規則，管理員背景自動安全地過濾並清除斷線遺留的幽靈孤兒帳號。
