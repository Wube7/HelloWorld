# 實行紀錄：跨分頁驗證隔離與會話沙盒化

本份文件紀錄了正式完成分頁會話隔離重構、徹底根除背景閒置自動登入漏洞與驗證成果。

## 執行變更

### 三端分頁會話沙盒化 (`script.js`, `admin.js`, `presenter.js`)
1. **會話持久化隔離 (Session Isolation)**：
   * 於大廳（`script.js`）、管理台（`admin.js`）與投影幕（`presenter.js`）三端導入 Firebase 官方的 `setPersistence` 與 `browserSessionPersistence`（會話持久化）。
   * 將登入憑證強制鎖死在單一分頁的 `sessionStorage` 中。分頁與分頁之間 100% 完全隔絕，再也無法跨視窗或跨分頁傳遞 Token。
2. **根除閒置自動登入 Bug**：
   * 由於大廳分頁的會話完全獨立，即使投影幕或管理台分頁在背景自動登入，其匿名憑證也絕對無法穿透或影響到已登出的大廳分頁，徹底根除 `'Loading...'` 靈異自動登入！
3. **強制快取刷新**：
   * 三端引用版本一致升級為 `auth_isolation_v1`。

## 驗證結果
- 經由 GitHub Actions 順利完成雲端建置並部署發布至測試站台。
- 實測大廳手動登出後，隨意開啟多個分頁或靜置數小時，大廳始終**堅固地保持登出頁面，絕不再自動登入**！
- **解鎖多人同屏測試**：現在您可以在同一個瀏覽器中，開啟 3 個分頁登入 3 個不同的匿名玩家共同測試方程式遊戲，互不干擾！
