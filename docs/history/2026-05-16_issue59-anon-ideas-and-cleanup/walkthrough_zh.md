# 實行紀錄：實作創意徵集匿名模式與大廳版面清理

本份文件紀錄了為排查大廳殘留舊結果橫幅與保障點子發表隱私，所完成的生命週期重構與匿名開關成果。

## 執行變更

### 全端版面大掃除與名稱遮罩 (`admin.html`, `admin.js`, `script.js`, `presenter.js`)
1. **全域大廳清理 (`script.js`, `presenter.js`)**：
   - 將 `idle` 階段手動隱藏舊容器的做法，全面升級為呼叫全域 `hideAll()`。
   - 不論管理員點選結束問卷或重設創意徵集，所有客戶端與展示大螢幕秒速乾淨退回純白大廳，毫無舊數據殘留。
2. **匿名徵集模式 (`admin.html`, `admin.js`)**：
   - 於管理台題庫上方新增精緻的 `🥷 Anonymous Ideation Mode` 切換開關。
   - 開啟時，全場卡片上的發布者全數化名為 `'🥷 Anonymous'`（作者本機顯示 `You`），同時底層維持 UID 比對，完美守護禁止自推防線。

## 驗證結果
- 經由 GitHub Actions 順利完成雲端建置並自動發布至測試站台。
- 結束或重設模式後，網頁極致純淨返回大廳。
- 啟用匿名模式發布點子，全場完美遮罩真實姓名，隱私與操作防護兼顧。
