# 實行紀錄：解耦進行中控制列與 hideAll 及解鎖結束鍵修復 KBC 死鎖

本份文件紀錄了為排查更新或重整時 KBC 按鈕消失造成的死鎖，所完成的可見性解耦與按鍵永久解鎖成果。

## 執行變更

### 可見性解耦與終極控場權力 (`admin.js`)
1. **解耦 `hideAll`**：
   - 將 `#admin-active-kbc-controls` 移出全域隱藏清單，僅於退回大廳 `idle` 時隱藏。保證在作答中重整網頁時操作列穩定顯現。
2. **永久解鎖完賽與退回大廳**：
   - 在任何進行中階段（作答、揭曉、頒獎），永久啟用 `End Game` 與 `Return Lobby`。賦予活動主持人在遭遇非同步卡死或中斷時一鍵解鎖的至高控制權。

## 驗證結果
- 經由 GitHub Actions 順利完成雲端建置並自動推送至測試站台。
- 於 KBC 競賽中途按下 F5 重新載入，管理員控制框精準顯現。
- 點擊 `End Game` 順暢跳轉加冕畫面，死鎖徹底消除。
