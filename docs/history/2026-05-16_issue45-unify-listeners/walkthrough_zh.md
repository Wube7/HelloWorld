# 實行紀錄：統一後台與展示腳本延遲監聽生命週期

本份文件紀錄了為徹底貫通全站三支核心腳本的非同步時序，消除管理員後台與大螢幕展示在初開啟時因未登入造成 Firebase 永久銷毀監聽器的死角，所進行的底層大一統成果。

## 執行變更

### 全域生命週期大一統 (`admin.js`, `presenter.js`)
- 將 `script.js` 裡經受嚴格考驗的非同步延遲監聽架構 (`initDatabaseFuncs`) 完整貫通至 `admin.js` 與 `presenter.js`。
- 確保三支腳本在剛開啟頁面時絕對不綁定監聽器，只有在身實驗證成功 (`onAuthStateChanged`) 的當下，才會精準啟動對 `presence`, `users`, 遊戲模組等節點的即時同步。
- 完美杜絕了管理員剛開網頁時因未登入導致監聽夭折，進而使 KBC 啟動時讀不到 `onlinePresence` 而套用 Anonymous 的連鎖 Bug。

## 驗證結果
- 經由 GitHub Actions 順利完成雲端建置並自動推送至測試站台。
- 重整後開啟管理員或展示大螢幕，各項數據即時連動，KBC 啟動時精準展示參賽者動物名稱，全站資料流達到無與倫比的流暢與統一。
