# Release Notes: v2.3.0 (Simultaneous Equation Revamp & Wide Chronological Decoder)

We are thrilled to announce the release of **v2.3.0** of the Brainstorm Room web application! This release deploys a highly sophisticated revamp to the Cooperative Equations Game mode, replacing basic arithmetic with a fully cyclic, pseudo-single-connected simultaneous linear equation matrix, and introduces a gorgeous, wide-screen horizontal double-column side-by-side Presenter interface with chronologically ordered tracking and custom scrollbars.

---

## 🌟 Major Highlights

### 1. Pseudo-Single-Connected Cyclic Simultaneous Equation Redesign
- **Cyclic Co-op Formula System**: Redesigned the active game phase from basic arithmetic to a cyclic simultaneous equation matrix (`A = C - B + 2`, `B = D - C + 7`, etc.), forcing participants to share solved variable clues and solve as a single cohesive unit.
- **Scrambled Solved Constants**: Obfuscated individual solved player equation cards (e.g., `A = 8 - 4 + 1` instead of simply `A = 5`) to prevent participants from guessing the final passcode sum (`27`) by simply adding up all visible constants.
- **Decoupled Group Structures**: Restructured variables and operators to avoid deadlocks, ensuring mathematical solvability under all participant allocations.
- **Randomized Dynamic Warm-up**: Switched the Warm-up phase from static templates to dynamically generated linear systems (`2A - B = X`, `2B - A = Y`) with dynamically matching passcodes, ensuring 100% robust, cheating-resistant calibration.

### 2. High-End Wide Horizontal Side-by-Side Presenter Sidebar
- **Chronological Decrypting Progress Flow**: Re-engineered the dynamic Presenter sidebar to place **`⏳ DECODING...`** on the left and **`🔒 VAULT DECODED`** on the right, creating a natural chronological left-to-right movement flow as players submit correct passcodes.
- **Wider Sidebar Flexbox Configuration**: Expanded the layout grid to allocate a spacious `flex: 1.9` to the active progress columns, allowing multiple nicknames to fit comfortably without text clipping.
- **Clean Vertical Scrollbars**: Injected `overflow-y: auto` styling with scrollbars into both progress cards, keeping the lists clean, responsive, and perfectly readable under high participant concurrency.
- **Vertical Clue Alignment**: Replaced fixed vertical constraints with a `min-height: 420px` grid configuration, stretching the side-by-side cards vertically to achieve a perfect, premium symmetrical alignment with the primary mission description panels on the left.
- **Narrative Cleanup**: Simplified the Warm-up presenter clues layout by removing redundant narrative labels (`First/Second Operator Relation:`), presenting algebraic formulas directly in a clean, professional monospace font.
