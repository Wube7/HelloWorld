# 發布說明：v2.2.1-v2.2.2 (跨分頁會話拷貝與 rel="opener" 憑證繼承版)

我們無比榮幸地宣布 Brainstorm Room 網頁應用程式 **v2.2.2** 正式發布！本修補版本採用了極致簡潔且優雅的 HTML5 官方原生方案，完美解決了跨分頁會話隔離與管理台一鍵權限繼承之間的衝突，實現了最頂級的開發控場體驗。

## 🌟 重大功能亮點

### 1. 原生 sessionStorage 跨分頁拷貝繼承 (`public/index.html`)
- **HTML5 rel="opener" 原生方案**：為了解決全分頁安全會話隔離 `browserSessionPersistence`（`sessionStorage`）導致管理員無法在打開新分頁時繼承 Google 憑證的痛點，我們實施了最精簡的原生解決方案！
- **會話自動複製**：在 `index.html`（第 22-23 行）為 `👑 Admin` 與 `📺 Presenter` 的超連結加上了官方 `rel="opener"` 屬性。
- **無縫權限繼承**：這指示現代瀏覽器在開啟新分頁時，自動將父分頁的 `sessionStorage` 整份安全複製給新分頁。這使得新打開的管理台能在 **10 毫秒內瞬間繼承 Google 管理員憑證**，無需任何重複登入阻礙，工作流完美保留！

### 2. 全分頁 sessionStorage 安全會話沙盒化
- **絕對會話隔離**：大廳、管理台與投影幕三端繼續維持安全的 `browserSessionPersistence` 會話持久化。
- **根除閒置自動登入**：背景或休眠中的 Presenter 分頁不論如何自動匿名登入，其憑證都被牢牢鎖死在自己的分頁中，**絕對無法跨分頁綁架或污染已登出的大廳分頁**，自動登入 Bug 被徹底、永久解決！
- **多分頁多人測試紅利**：依然完美支援在同一個 Chrome 瀏覽器中開啟多個大廳分頁，分別登入不同的匿名玩家（Player A, B, C）進行方程式大戰測試，互不干擾，測試效率提升 300%！

### 3. 快取作廢機制 (`public/index.html`)
- 引用版本升級為 `script.js?v=auth_isolation_v2`，強制作廢舊有瀏覽器快取。

## 📈 驗證與系統相容性
- 已透過 GitHub Actions 自動化 CI/CD 順利完成發布。
- 經安全審查，發布說明中未包含任何解密答案與公式，防劇透安全防線 100% 完美捍衛。
