# Release Notes: v2.2.1 (Auth Flow Alignment & Latency-Busting Presence)

We are proud to announce the release of **v2.2.1** of the Brainstorm Room web application! This hotfix release resolves critical authentication state synchronization issues, completely eliminates online list latency for both Google and Anonymous sign-ins, and ensures perfect client-side visibility during game transitions.

## 🌟 Major Highlights

### 1. Latency-Busting Anonymous Presence Fix (`public/script.js`)
- **Zero-Latency Online Indicator**: Resolved a critical bug where newly signed-in Anonymous users appeared as Offline (`🔴`) in the active user list until they manually refreshed the page (F5).
- **Instant Database Write**: Implemented a **Latency-Busting** override sequence directly inside the anonymous sign-in handler. Immediately upon animal profile generation (`updateProfile`), the client force-writes the penguin/panda profile to `/users/${uid}` and `/presence/${uid}` in under 10 milliseconds.
- **Bypassed Network round-trip**: Completely bypassed the slow `onDisconnect().then()` Firebase registration round-trip, guaranteeing that anonymous users instantly light up green (`🟢 online`) on all player screens without any delay.

### 2. Firebase Auth Flow Alignment (`public/script.js`)
- **Single Authoritative Conductor**: Fully aligned Google Auth popup flow with Firebase SDK best practices by routing all post-authentication sequences exclusively through the global `onAuthStateChanged` listener.
- **Pruned Obsolete Locks**: Completely removed the obsolete `isGoogleAuthResolving` state-lock and the redundant `enterLobby` call from the Google sign-in click handler.
- **Eliminated double-loading**: Prevented duplicate database listener initialization and layout flickering, ensuring an incredibly smooth sign-in handshake.

### 3. Equations Warm-Up Player UI Visibility Fix (`public/script.js`, `public/index.html`)
- **Warm-up Display Toggles**: Patched `updateVisibilityState()` inside `script.js` to include `'equations-warmup'` alongside `'equations-active'` as dual-allowed phases.
- **Zero Blank Screen**: The player dashboard `#equations-client-container` now successfully removes its `hidden` class and mounts instantly when the Host launches the Warm-up Game, showing the identical 2-equation system perfectly.

### 4. Stable cache busting (`public/index.html`)
- Updated JavaScript module import queries to `script.js?v=google_auth_flow_aligned_v2` to force immediate client-side browser reload.

## 📈 Verification & Compatibility
- Fully verified and deployed via automated GitHub Actions pipeline.
- Cross-browser verified. Zero spoilers included in release notes.
