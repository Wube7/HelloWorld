# 發布說明：v2.2.0 (方程式解碼器與控制台斷線防禦架構)

我們極其興奮且自豪地宣布 Brainstorm Room 網頁應用程式 **v2.2.0** 正式發布！這項劃時代的重大里程碑，為大廳引入了極具趣味性、完全隱蔽輔助、考驗深度社交工程的「聯立方程式解碼器（Equations Decoder）」雙階段模式，並為管理台總控指揮塔注入了固若金湯的「斷線重連／重整狀態同步」防禦機制。

## 🌟 重大功能亮點

### 1. 障眼法方程式解碼器模式 (`index.html`, `script.js`, `equations_config.js`)
- **完美字元對稱矩陣**：全體玩家螢幕上看到的加減號、常數與算式長度（強制定格在 17 字元）100% 完全物理對齊，創造出考卷相同的心理錯覺。僅有自己的專屬變數行，右側變數被替換為簡單算術。
- **嚴格數學防劇透**：隱藏整數解的安全驗證，所有替換數字在代數替換時均不等於答案本身，且不等於被取代變數，完美防劇透。
- **華麗金盃大卡片**：輸入 `32` 正確通關解鎖時，算式面板與輸入框自動隱退，釋出 80% 版面空間，並在原處升起帶有金色旋轉獎盃動畫的 glassmorphic 華麗通關大卡片。
- **完全無提示解謎**：徹底刪除了通關與啟動時向聊天室發布的廣播，讓玩家回歸最純粹的口頭交流或手寫文字串供，氣氛極度拉滿。

### 2. 可口可樂秘方主題 Presenter 看板 (`presenter.html`, `presenter.js`)
- **機密配方情報簡報**：Presenter 投影幕展示 leaked Coca-Cola 秘方情報，6 大核心材料（糖、水、焦糖色素等）對應 A~F 克。
- **完美垂直切齊表格**：使用高雅 HTML `<table>` 排版取代文字條列式，在畫面上垂直切得無比工整整齊。
- **實時計數進度條**：頂部新增紅色精美狀態橫幅 `👥 Decoded Progress: X / Y Players`，實時追蹤大廳破解人數。

### 3. 二元一次聯立方程式熱身賽 (`🎲 Warm-up Game`)
- **標準對稱破冰關卡**：正式賽前支援啟動標準二元一次方程式熱身賽（`A + A - B = 10`、`B + B - A = 1`），並支援匹配驗證密碼 `11`，點燃解題氣氛。

### 4. 控場保險栓：管理台斷線重整同步 (`admin.js`)
- **重載與斷線防禦**：在 `updateVisibilityState()` 的清場階段注入安全防禦閥值。重整時，若 Ideation、Survey 正在資料庫活躍進行中（`active: true`），面板將跳過隱藏、**完美保持展開狀態**！
- **狀態列即時回正**：當管理員斷線重連進入時，頂部 Room Banner 立刻回正為 `"💡 IDEATION ROOM in Progress"` 或 `"📊 SURVEY ROOM"`，控制權限完美保留！

### 5. 安全實時資料庫規則擴充 (`database.rules.json`)
- 擴充 `/admin/equationsState` 安全授權，開放在線玩家向自己的 `/admin/equationsState/players/$uid/solved` 寫入 `true`，確保即時計數器防禦性運作。

## 📈 驗證與系統相容性
- 經由自動化 GitHub Actions 管道順利建置並部署發布至測試與正式雲端站台。
- 完美相容所有主流瀏覽器（Chrome, Safari, Firefox, Edge），在暗黑與亮白雙主題模式下皆具備完美的視覺與高對比度閱讀體驗。
