# 發布說明：v2.1.0 (多題庫總控架構與實時診斷主控台)

我們極其興奮且自豪地宣布 Brainstorm Room 網頁應用程式 **v2.1.0** 正式發布！這項劃時代的重大里程碑，將管理控制台從早期的單一問答展示，徹底躍升為具備持久化存儲、底層數據實時透明化與極致強大互斥防護的多題庫終極主控台！

## 🌟 重大功能亮點

### 1. 持久化多題庫問答總控 (`admin.html`, `admin.js`)
- **無上限自訂題庫**：管理員現在可以建立多組專屬問答題庫 (`#quiz-bank-list`)，直接持久化保存於 Firebase 雲端資料庫 (`/admin/quizBanks`) 中。
- **自訂秒數與主題**：每組題庫皆支援設定專屬題目集、自動倒數跳題秒數 (0-300秒) 與清晰的自訂主題名稱。
- **賽後歷史封存**：每場賽局結束瞬間，系統會自動將全體玩家積分榜與完賽時間封存至 `lastSession`，供管理員隨時調閱回顧。

### 2. 實時診斷全域狀態橫幅 (`admin.html`, `admin.js`)
- **底層數據極致透明**：管理台最上方建置了一座極其亮眼的狀態橫幅 (`#admin-room-status-banner`)，實時反映底層資料庫的 `active` 布林值、當前房間模式 (`LOBBY`, `QUIZ`, `KBC`, `SURVEY`, `IDEATION`) 以及精確的題目或回合索引。
- **視覺化色彩導航**：翠綠色大廳待命、深紫色問答進行中、粉紅與青綠色指示選美及問卷進度，狀態一目了然。

### 3. 上帝保險栓：緊急大廳總開關 (`#btn-emergency-lobby`)
- **一鍵強行解鎖死鎖**：為了預防將來任何不可預期的網路中斷或快取殘留，頂部橫幅常駐保留了 `"🚨 Force Unlock All Modes (Master Reset to Lobby)"` 紅色緊急按鈕！按下一鍵，系統瞬間向四大競賽節點同步發布 `active: false` 關閉廣播，強制解開所有客戶端互斥鎖，滿血重置全體大廳！

### 4. 優雅動態問答指揮塔 (`#admin-active-quiz-controls`)
- **動態優雅收攏與升降**：與 Survey 和 KBC 架構完美對齊，問答進行中控制面板在大廳待命時保持乾淨收攏，當比賽啟動秒速順暢滑出。
- **全域控場按鍵群**：支援 `Next Question` 手動跳題、`End Game (Crown Winner)` 提早結束加冕與 `Return Lobby` 退回大廳。

### 5. 零 ReferenceError 與消除計時器競態 (`admin.js`, `script.js`)
- **徹底根除當機死鎖**：汰換並清空了殘留的舊版上傳按鍵變數，徹底根絕 Strict Mode 下引發的未宣告變數當機。
- **元數據展開完整繼承**：自動與手動跳題寫入完美展開繼承 (`...state`)，確保 `bankId` 與倒數計時秒數在每一輪中完美連貫。
- **唯一發言權**：徹底移除了玩家展示端 (`script.js`) 的跳題控制器，使計時發布權力 100% 歸一於管理控制台，杜絕競態寫入衝撞。

## 📈 驗證與系統相容性
- 經由 GitHub Actions 自動化 CI/CD 管道完成完整建置，並順利發布至測試與正式雲端站台。
- 完美相容所有現代桌上型與行動裝置網頁瀏覽器 (Google Chrome, Safari, Firefox, Edge)。
