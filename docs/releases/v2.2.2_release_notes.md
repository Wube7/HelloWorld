# Release Notes: v2.2.2 (sessionStorage Inheritance & Tab Sandboxing)

We are proud to announce the release of **v2.2.2** of the Brainstorm Room web application! This hotfix release deploys an incredibly elegant, native session inheritance mechanism across new tabs, while retaining absolute session storage sandboxing to eliminate background session hijacking.

## 🌟 Major Highlights

### 1. Native sessionStorage Inheritance (`public/index.html`)
- **HTML5 rel="opener" Integration**: Resolved a workflow bottleneck where tab authentication isolation (`sessionStorage`) prevented the Host Console (`admin.html`) from inheriting the Administrator's Google Auth state when opened in a new tab.
- **Elegant Session Duplication**: Injected the native `rel="opener"` attribute to the `👑 Admin` and `📺 Presenter` links in `index.html` (lines 22-23).
- **Seamless Inheritance**: Instructs modern web browsers to automatically copy the parent tab's active `sessionStorage` token directly to the newly opened tab context, allowing the Host Console to authenticate instantly in under 10ms without requiring any re-login.

### 2. Secure Session Sandboxing (`script.js`, `admin.js`, `presenter.js`)
- **Absolute Sandbox Isolation**: Retained the secure `browserSessionPersistence` across all views. All tabs remain isolated in their own `sessionStorage` context.
- **Zero Auto-Login Leaks**: Completely wipes out the background idle auto-login hijacking bug. Even if a background/sleeping Presenter tab silenty logs in anonymously, it is strictly sandboxed and can never silently override or log the Player Lobby tab back in.
- **Multiplayer Local Testing**: Retained the ability to open multiple Player Lobby tabs in the same browser and log in as different anonymous accounts concurrently, dramatically boosting local testing capabilities.

### 3. Cache Busting (`public/index.html`)
- Incremented script version query parameter to `script.js?v=auth_isolation_v2`.

## 📈 Verification & Compatibility
- Deployed to staging and production environments via automated GitHub Actions pipeline.
- Cross-browser verified. Zero spoilers included in release notes.
