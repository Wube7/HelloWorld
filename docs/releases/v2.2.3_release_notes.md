# Release Notes: v2.2.3 (Landscape Projection & Double-Click Zoom Mode)

We are thrilled to announce the release of **v2.2.3** of the Brainstorm Room web application! This release deploys highly optimized wide-screen landscape layout enhancements to utilize projector screens fully, introduces a beautiful interactive double-click lightbox zoom mode with screen dimming, and upgrades timestamps to include date information across both participant and presenter views.

---

## 🌟 Major Highlights

### 1. Presenter Wide-Screen Landscape Layout Extensions
- **96vw Viewport Stretching (`public/styles.css`)**: Extends the presenter `.container` max-width from `1200px` to **`96vw`**, fully utilizing horizontal screen space on typical landscape 1080p/4K projectors.
- **Grid Column Auto-Fill**: Cards now automatically reflow and stretch (min-width `320px`) into **6 columns or more** on wide projection displays, increasing parallel information density.
- **Bottom Blank Margin Wiped**: Reduced the unnecessary bottom margin on `#idea-presenter-container` to `1rem`, fully filling the vertical space.

### 2. Interactive Double-Click Lightbox Zoom (`presenter.js`, `styles.css`)
- **Perfect Clutter-Free Readability**: Double-clicking (`dblclick`) any idea card on the Presenter screen triggers a lightbox modal which scales the card by **1.45x** and centers it perfectly.
- **Keyring/Stacking Context Shadow Dimming**: Solved typical CSS z-index rendering and click-blocking traps (caused by parent glass-panels backdrop filters) using a self-contained **`100vmax` box-shadow mask** (`box-shadow: 0 0 0 100vmax rgba(15, 23, 42, 0.65)`). The background dims elegantly, keeping the zoomed card 100% sharp and highly readable.
- **Select & Copy Retention**: Triggering zoom via double-click leaves single-click and drag completely free, allowing hosts to **select and copy text** seamlessly.
- **Toggle to Restore**: Double-clicking the card again smoothly restores it, with all other card zooms automatically cleared first to maintain a single active focus.
- **Card Height Limit & Scrollbar**: Typical cards are constrained to **6 lines of text** (`max-height: 17.3rem`) with a custom elegant scrollbar to keep the grid perfectly symmetric, automatically expanding to full-text when zoomed.

### 3. Double-End Date Timestamp Representation (`presenter.js`, `script.js`)
- **Date Traceability**: Upgraded timestamps on idea cards across both the Live Presenter screen and Client Lobby to use `toLocaleString` format including month and day (e.g., **`5/21, 13:42`**), allowing teams to trace brainstorming timelines accurately over multi-day workshops.
