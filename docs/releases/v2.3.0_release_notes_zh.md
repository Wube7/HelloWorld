# 發布說明：v2.2.3-v2.3.0 (聯立方程式改版與雙欄水平解密牆)

我們無比興奮地宣布 Brainstorm Room 網頁應用程式 **v2.3.0** 正式發布！本版本針對「聯立方程式合作解密（Equations Game）」遊戲模式進行了全方位的底層數學架構與主講人介面革新，將以往的簡單算式升級為極具挑戰性的「偽單一連通循環線性聯立方程組」，並引入了全新的大螢幕水平側邊雙欄排版、左進右出流暢過關動畫與獨立滾動條支持。

---

## 🌟 重大功能亮點

### 1. 偽單一連通循環線性聯立方程式全面改版
- **循環合作公式架構**：將正式解密階段的算式升級為首尾相連的循環聯立方程組（`A = C - B + 2`, `B = D - C + 7` 等），迫使參賽者互相分享獲得的專屬變數值才能通關。
- **專屬解常數混淆**：在每位玩家分配到的已解公式中進行了常數混淆（如顯示 `A = 8 - 4 + 1` 代替直接顯示 `A = 5`），防止參賽者透過單純加總所有卡片常數來作弊猜測出最終密碼（`27`）。
- **解耦變數組結構**：精心編排變數與運算元分配，避免死鎖，確保在各種人數配置下均有唯一的數學解。
- **隨機化動態 Warm-up**：將 Warm-up 暖身階段從靜態模板升級為動態隨機生成的二元一次線性方程組（`2A - B = X`, `2B - A = Y`）並動態生成匹配的密碼，達到 100% 的動態防弊防猜。

### 2. 高端大螢幕水平側邊雙欄排版 (Presenter View)
- **左進右出解密進度流**：重新調整排版，將 **`⏳ DECODING...`**（解密中）放置於左邊，**`🔒 VAULT DECODED`**（已過關）放置於右邊，構建極具視覺衝擊力的「左進右出」實時通關進度動態。
- **雙欄水平並列拉寬**：將進度牆的寬度佔比拉寬至 `flex: 1.9`，讓參賽者名字與被分配的變數代號有足夠的空間排版，防止字元擠壓或折行。
- **內建縱向滾動條**：為兩張進度卡片引入 `overflow-y: auto` 及滾動條，確保在高併發、多人同場競技時，名單依然整齊流暢，不影響大螢幕整體美感。
- **垂直高度完美對齊**：將進度牆的最小高度調整為 `min-height: 420px`，與左側的主線任務提示（Mission Clues）完美等高對齊，視覺結構更為大氣對稱。
- **去除贅餘文字提示**：移除了 Warm-up 線索中冗餘的敘述字眼（`First/Second Operator Relation:`），直接乾淨呈現代數公式，帶來極簡的高科技質感。
