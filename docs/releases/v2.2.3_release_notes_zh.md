# 發布說明：v2.2.2-v2.2.3 (寬螢幕投影延伸與雙擊燈箱聚焦版)

我們無比興奮地宣布 Brainstorm Room 網頁應用程式 **v2.2.3** 正式發布！本版本針對主講人投影幕（Presenter View）進行了全方位的寬螢幕與高解析度景深優化，引入了極致流暢的雙擊燈箱想法放大功能，並為參與者與主講人雙端的時間戳記升級了日期追溯支持。

---

## 🌟 重大功能亮點

### 1. 主講人全螢幕橫向投影延伸 (`public/styles.css`)
- **96vw 橫向滿版延伸**：將主講人 `.container` 的最大寬度限制從 `1200px` 拓寬延伸至 **`96vw`**，大幅利用橫向投影展示空間。
- **自動填滿 6 列以上卡片**：卡片最小寬度調整為 `320px`。在 1080p 或 4K 投影幕上，卡片將自動併排為 **6 列以上**，資訊密度提升 150%。
- **消除底部多餘留白**：將 `#idea-presenter-container` 的底部外邊距（`margin-bottom`）縮減至 `1rem`，讓想法牆完美沉降填滿垂直空間。

### 2. 雙擊燈箱聚焦放大模式 (`presenter.js`, `styles.css`)
- **高對比焦點聚焦**：在投影幕上**快速雙擊兩下 (Double Click)** 任何一張卡片，該卡片會平滑放大 **1.45 倍**並位移置中。
- **繞過堆疊上下文陰影暗化**：利用卡片自身的 **`100vmax` 超大陰影擴張** (`box-shadow: 0 0 0 100vmax rgba(15, 23, 42, 0.65)`)，繞過因父層毛玻璃 `backdrop-filter` 產生的 z-index 阻擋與文字模糊 Bug。背景會平滑暗化，大卡片文字保持 **100% 絕對清晰銳利**！
- **完整保留選取複製**：雙擊觸發機制讓單擊拖曳完全保留，主講人仍能**自由點選、拖曳並複製（Copy）文字**。
- **卡片限高與雙擊還原**：典型卡片被高度限制在 **6 行內** (`max-height: 17.3rem`) 並自帶滑順滾動條以保持牆面完美整齊對稱；**雙擊放大時會自動解除高度限制展開全文**，再次雙擊即還原！

### 3. 雙端時間戳記加入日期 (`presenter.js`, `script.js`)
- **日期精準追溯**：將主講人投影幕與大廳參與者雙端卡片的時間戳記統一升級為 `toLocaleString` 格式，顯示為 **`5/21, 13:42`** (月/日, 時:分)，助於在跨日工作坊或馬拉松會議中精確追溯想法發表時間。
