# Release Notes: v2.1.0 (Multi-Bank Master Architecture & Diagnostic Console)

We are thrilled to announce the release of **v2.1.0** of the Brainstorm Room web application! This major milestone transforms the host administration console from a static single-quiz layout into an enterprise-grade, multi-bank persistent conductor with absolute real-time diagnostic transparency and robust synchronization.

## 🌟 Major Highlights

### 1. Persistent Multi-Bank Quiz Master (`admin.html`, `admin.js`)
- **Unlimited Custom Banks**: Host administrators can now save multiple custom quiz banks (`#quiz-bank-list`) directly to the Firebase database (`/admin/quizBanks`).
- **Custom Timers & Topics**: Every saved quiz bank preserves custom question sets, countdown timers (0-300s), and descriptive topic titles.
- **Historical Session Archiving**: Each game automatically archives its participants, final standings, and timestamps to `lastSession` upon completion, allowing administrators to review historical performance anytime.

### 2. Real-Time Diagnostic Room Status Banner (`admin.html`, `admin.js`)
- **Absolute State Transparency**: A prominent status banner (`#admin-room-status-banner`) now anchors the top of the host dashboard. It continuously tracks real-time database booleans (`active`), active room modes (`LOBBY`, `QUIZ`, `KBC`, `SURVEY`, `IDEATION`), and precise round/question indices.
- **Dynamic Visual Cues**: Emerald green for lobby readiness, deep purple for active quiz rooms, magenta for KBC contests, and emerald/blue for surveys and ideation.

### 3. Emergency Master Reset Safeguard (`#btn-emergency-lobby`)
- **One-Click Mutex Unlocking**: To absolutely guarantee room stability against unhandled disconnects or cached ghost flags, an emergency master reset button (`"🚨 Force Unlock All Modes"`) is permanently mounted on the header. Clicking it instantly broadcasts `active: false` across all room backend endpoints, unlatching stalled client mutexes and returning all users to a pure lobby state.

### 4. Dynamic Active Quiz Console (`#admin-active-quiz-controls`)
- **Elegant Dynamic Mounting**: Aligned with Survey and KBC architecture, the active Quiz Master control box cleanly collapses during lobby idle times and dynamically slides into view when a quiz starts.
- **Conductor Progression Handlers**: Robust asynchronous controls for `Next Question`, `End Game (Crown Winner)`, and `Return Lobby`.

### 5. Zero ReferenceError & Timer Racing (`admin.js`, `script.js`)
- **Flawless Strict Mode Declarations**: Pruned all orphaned legacy upload variables and cleanly declared all active DOM elements, eliminating script lockup exceptions.
- **Perfect Metadata Spreading**: Automated question transitions now spread full state attributes (`...state`), ensuring `bankId` and timer durations inherit perfectly across every question.
- **Single Authoritative Conductor**: Isolated auto-jump timer controls solely inside `admin.js`, preventing client presentation scripts (`script.js`) from causing backend write race conditions.

## 📈 Verification & Compatibility
- Fully tested and deployed across testing staging and production environments via automated GitHub Actions CI/CD pipeline.
- Compatible with all modern desktop and mobile web browsers (Google Chrome, Safari, Firefox, Edge).
