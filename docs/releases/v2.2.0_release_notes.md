# Release Notes: v2.2.0 (Equations Decoder & Host Sync Resilience)

We are thrilled to announce the release of **v2.2.0** of the Brainstorm Room web application! This major milestone introduces the highly engaging, zero-assist **Equations Decoder** game modes (both Warm-up and Main puzzle phases) featuring a syntactically aligned symmetric visual illusion, and equips the Host command dashboard with absolute state-sync resilience during page refreshes or brief disconnects.

## 🌟 Major Highlights

### 1. Silent Equation Decoder Game Mode (`index.html`, `script.js`, `equations_config.js`)
- **Syntactically Symmetric Matrix**: Every player receives an identical-looking equation list. The operators, constants, and character lengths (strictly locked to 17 characters) align perfectly. For each player's specific role, the variables are replaced by simple single-digit arithmetic.
- **Mathematical Safeguards**: Solved values ($A=6, B=4, C=8, D=2, E=5, F=7$) are verified, and digit replacements (e.g., $C = 6 + 9 - 2 - 5$, $D = 3 + 9 - 6 - 4$) are strictly guaranteed to be different from the variables they replace to prevent answer leaks.
- **Confetti Victory Card overlay**: Upon successfully submitting passcode `32`, the entire equations grid and submission input form hide dynamically to release 80% of screen space, revealing a magnificent glassmorphic victory card with a golden trophy icon.
- **Zero-Assist Design**: Completely pruned all automated chatroom system logs and cooperation tags to maintain a pure, verbal, or manually written social puzzle-solving experience.

### 2. Themed Presenter Live Debrief (`presenter.html`, `presenter.js`)
- **leaked Secret Coca-Cola Recipe**: The Presenter screen displays a highly classified intel debrief outlining the leaked Coca-Cola formula weights governed by A to F.
- **Clean Aligned Table**: Displays ingredients (Sugar, Water, Caramel Color, Phosphoric Acid, Caffeine, Natural Flavorings) beautifully aligned vertically in a clean HTML table.
- **Real-Time Solved Counter**: Includes a high-visibility counter banner displaying `"👥 Decoded Progress: X / Y Players"` tracking live client completion statuses in real time.

### 3. Equations Warm-Up Mode (`🎲 Warm-up Game`)
- **Standard Symmetric System**: Conducts a 2-variable warm-up round ($A+A-B=10, B+B-A=1$) before the main puzzle to break the ice.
- **Passcode 11 Validation**: Dynamically resolves and verifies passcode `11` during the warmup phase, and binds with the presenter status progress counter.

### 4. Absolute Host Controls Sync Resilience (`admin.js`)
- **Refreshes & Disconnect Safeguards**: Inside `updateVisibilityState()`, we injected conditional guards to prevent active Ideation, Survey Rating, and KBC control panels from aggressively collapsing when `currentQuizPhase` is evaluated as `'idle'` during page reloads.
- **State Sync Restoration**: Survey and Ideation listeners now actively invoke re-renders upon loading, allowing administrators to reload `admin.html` or return from offline during live sessions with 100% of their active controls beautifully restored.

### 5. Robust Firebase Security Rules Expansion (`database.rules.json`)
- Expanded `/admin/equationsState` secure rules. Granted read permissions (`.read`) to authenticated users and write permissions (`.write`) strictly to the administrator email, while allowing active players to securely write `solved: true` to their own `/admin/equationsState/players/$uid/solved` nodes.

## 📈 Verification & Compatibility
- Fully verified and deployed to production via automated GitHub Actions CI/CD pipeline.
- Fully compatible across Chrome, Safari, Firefox, and Edge web browsers. High-contrast readability guaranteed in both dark and white theme modes.
