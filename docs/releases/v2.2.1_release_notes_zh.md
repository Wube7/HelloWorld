# 發布說明：v2.2.0-v2.2.1 (登入流標準歸一與匿名者極速上線綠燈版)

我們無比榮幸地宣布 Brainstorm Room 網頁應用程式 **v2.2.1** 正式發布！本修補版本重點攻克了驗證狀態同步的底層架構問題，徹底消除了 Google 與匿名登入在線列表的顯示延遲，並完美修復了大廳熱身賽的顯示漏洞。

## 🌟 重大功能亮點

### 1. 匿名者登入「極速即時上線」修補 (`public/script.js`)
- **秒速綠燈指標**：徹底修復了新登入的匿名玩家在 Users 名單中顯示為 `🔴 離線`，必須按 F5 重整才能看到 `🟢 在線` 綠燈的陳年頑疾。
- **極速直接寫入架構**：在匿名登入 click 事件中，當動物暱稱（例如 `🥷 Penguin`）一生成，**立刻以毫秒級速度主動向資料庫寫入** `/users/${uid}` 設定檔與 `/presence/${uid}` 在線節點。
- **繞過慢速網路回呼**：完全繞過了 `onDisconnect().then()` 慢速註冊監聽的網路往返時間差，確保匿名用戶登入成功的瞬間，在所有玩家螢幕上**即刻亮起在線綠燈**！

### 2. Google 登入標準流程歸一架構 (`public/script.js`)
- **全域權威指揮塔**：將 Google 登入流程與 Firebase SDK 最佳實踐完美對齊。廢除了臨時防重置變數 `isGoogleAuthResolving`，並移除了點擊事件中冗餘的 `enterLobby` 呼叫。
- **避免重複加載**：現在不論 Google 或匿名登入，全權交由 `onAuthStateChanged` 全域唯一監聽器進行收編。這精準防止了重複呼叫導致的大廳閃爍與資料庫重複綁定，加載順暢如絲。

### 3. 熱身賽大廳面板顯示漏洞修復 (`public/script.js`, `public/index.html`)
- **雙階段顯示重寫**：在 `updateVisibilityState()` 內將 `'equations-warmup'`（熱身賽階段）加入為雙重容許顯示階段。
- **消除白屏**：修復了管理台點擊「🎲 Start Warm-up Game」時，玩家端大廳面板因為被隱藏而顯示全白的問題。現在解鎖大廳與兩行算式會即時、完美地出現在玩家螢幕上。

### 4. 快取作廢機制 (`public/index.html`)
- 引用版本升級為 `script.js?v=google_auth_flow_aligned_v2`，強制作廢瀏覽器舊有快取。

## 📈 驗證與系統相容性
- 已透過 GitHub Actions 自動化 CI/CD 完成雲端發布。
- 經防劇透安全審查，未包含任何解鎖密碼提示，遊戲神祕感獲得 100% 完美捍衛。
